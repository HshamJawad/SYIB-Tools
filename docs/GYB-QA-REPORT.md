## Defects found and fixed during Phase 7

1. Returning to GYB from another tool always opened the home page instead of the last section. Fixed: the shell now resumes the module's current section (`SIYBGyb.current()`); explicit sidebar items still open their own section.
2. Test-side corrections only (not app defects): ideas transferred from activities were not counted, Arabic-Indic digits in costing inputs, and a logo scan that matched the licence disclaimer sentence.

Fixed in earlier phases while testing: locale-digit rewriting of option values in knowledge checks (now letters) and single-key store path updates.

## Known issues and limits

- Arabic wording of the readiness areas, cases, questions and licence disclaimers is new adapted text and has not been reviewed by a subject expert or trainer.
- Tested only in Chromium with emulated devices. Real phones/tablets, installed PWA, Safari/Firefox, screen readers and real PDF output of the print layout were not tested (see NOT RUN rows).
- Print / Save as PDF relies on the browser print dialog; no PDF file is generated by the app.
- GYB must be opened once online before it works offline (its scripts are cached on first use).
- The FRS asks for opening GYB from Training Mode; following the roadmap, GYB is its own sidebar tool (confirmed by the owner).
- No feasibility matrix, scoring, ranking or financial calculators exist, by design (FRS section 7).

## PoC readiness summary

All learner-journey items in FRS section 9 were completed through the real UI in the automated journey. Technical items (AR/EN, RTL/LTR, mobile/tablet/desktop, sidebar states, persistence and isolation, Costing and Stock regression, offline, no ranking) passed in the automated run. Remaining before a pilot: human review of Arabic content, a real-device test, and a trainer walkthrough.
